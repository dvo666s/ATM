# 🏦 Bank Management System

A console-based Banking System simulation built with **C++**, focused on practicing programming fundamentals through a practical project.

\<kbd>🚧 Under Development\</kbd>

## 📌 Overview

The project simulates basic banking operations and account management. Development starts with a procedural implementation, with a separate OOP version planned for a later stage.

## ⚙️ Current Features

- 👤 Initial client data structure and ID generation.
- 💳 Account setup and account type selection.
- 💱 Currency selection (USD, EUR, GBP).
- 💰 Initial savings account options.
- 📦 Savings plans with different benefits and interest rates.
- 🏧 Debit card selection.

*These features are still being developed; some workflows are incomplete.*

# Bank Management System

A Banking System simulation developed using **C++**.

This project is a practical programming project focused on building a banking system step by step, starting with procedural programming and gradually exploring more advanced software development concepts.

> **Project Status: Under Development**

The project is still being developed. Features, internal structure, and implementation may change as development progresses.

## Project Overview

The goal of this project is to simulate basic banking operations and account management through a console-based application.

The system is being designed around different banking entities, including clients, accounts, banking services, and savings plans.

Rather than focusing only on writing code, this project is also an opportunity to understand how a program is structured, how data is represented and managed, and how different components interact with each other.

## Current Development

The current implementation focuses on the initial banking data structures and account setup process.

The code currently includes initial implementations of:

- Client and account data structures.
- User ID generation.
- Account setup and account type selection.
- Currency selection (USD, EUR, and GBP).
- Initial savings account options.
- Savings plans and their proposed benefits.
- Debit card selection.

**Note:** These components are still under development. Some flows are incomplete and have not yet been fully integrated or tested.

## Project Goals

The project is intended to evolve through several development stages:

### 1. Procedural Version

Build the initial banking system using procedural programming concepts.

Planned development includes:

- Client and account management.
- Banking operations.
- Savings account plans and services.
- Input validation and error handling.
- Data management and file handling.

### 2. OOP Version

Develop a separate Object-Oriented version of the system.

This stage will focus on:

- Designing appropriate classes and responsibilities.
- Encapsulation and composition.
- Inheritance and polymorphism where appropriate.
- Defining relationships between clients and accounts.
- Organizing the system using a more structured design.

### 3. Further Improvements

Explore additional concepts as the project develops, including:

- UML diagrams and software design.
- Database concepts.
- Improved data management and persistence.
- Testing and code quality.

These are development goals, not features currently available in the application.
